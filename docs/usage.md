# 使用说明

完整解压程序后打开 QQArchiveNext.exe。它会识别相邻档案，或让你选择已有档案/迁移包。首次采集按仓库 README 运行 Configure-QQArchive.ps1；现有文件和目录不会覆盖。没有密钥时仍可阅读、验证和恢复已有完整档案。

## 界面和托盘

概览展示各来源最近成功、媒体巡检及运行状态。聊天记录支持全部会话、时间线、文字搜索和时间定位；来源与版本保留原始字段及已观测历史，媒体下载为副本。备份与恢复支持完整备份、固定点、逐文件验证、恢复和迁移包导出。

普通重试按 1、2、4、8、15 分钟静默退避，保留最近成功资料。状态与处理展示原因、次数、下次重试、重新检查及备份恢复入口。连续超过 30 分钟仍未成功，或认证、版本、完整性、空间等重要故障才提醒；同一故障最多 6 小时一次，系统通知至少间隔 15 分钟。可关闭重要系统通知。

窗口关闭默认留在托盘，重复打开共用实例；安全退出等待写入检查点。设置提供登录自启、登录后驻留托盘、关窗行为和桌面快捷方式。恢复到新电脑不会自动注册登录自启。独立浏览器入口可按需开启，只监听本机环回地址。

## 备份和换电脑

新建档案采用完整备份模式，包含恢复所需的源绑定材料。导出自己的完整迁移包后，复制整个目录。目标电脑运行 Start.cmd，按助手验证、恢复到新目录并打开。支持安全取消；未完成的恢复会保留标记，选择新的目标目录重试，不要覆盖原目录。

同盘复用冻结文件可节省空间，但仍共享文件字节。普通复制到其他卷后文件字节独立；同盘复用不能代替灾难备份。本次跨卷夹具验收不等于另一台实体电脑全量验收。复制过去后可离线浏览；继续采集新电脑来源需要重新核对本机来源、密钥和客户端版本。

## Agent

详情见 [Agent 接口](agent.md)。Agent 使用本地 CLI、共享任务队列和取消检查点，不需要操作 GUI。不要在聊天中粘贴源密钥或上传私人配置。
